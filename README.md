## ⚡ Как подключиться за 1 минуту

1. Скачайте и запустите **`PandaWorkerSetup.exe`**.
   - *Примечание о Windows SmartScreen:* так как проект бесплатный и не использует платную корпоративную подпись Microsoft EV ($400/год), при первом запуске Windows может показать синее окно *«Система Windows защитила ваш компьютер»*. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
2. Откройте Telegram-бота **[@panda_4k_bot](https://t.me/panda_4k_bot)** → раздел **«⚡ Пакет за GPU & Фарм ⭐️»** → нажмите **«🔑 Получить 6-значный код привязки»**.
3. Введите 6 цифр кода в окно программы.
4. **Готово!** Программа тихо в фоне докачает проверенные Vulkan-движки (`Real-ESRGAN`, `Real-CUGAN`, `RIFE`, `FFmpeg`), проведёт калибровку видеокарты и пришлёт уведомление прямо в Telegram, когда начнёт зарабатывать ваш пакет и лоты для Биржи ⭐️!

## 🛡 Полная прозрачность и безопасность

Весь исходный код клиента опубликован прямо в этом репозитории (`.py` модули и скрипт сборки `build_exe.ps1` — любой разработчик может изучить каждую строчку или собрать `.exe` самостоятельно):

- **0 открытых портов и 0 правок реестра:** программа работает строго через исходящие запросы и использует чистый ярлык в стандартной папке Автозагрузки Windows (`APPDATA\Microsoft\Windows\Start Menu\Programs\Startup`) без вмешательства в системный реестр `HKCU\Run`.
- **Никакого доступа к личным файлам:** работа ведётся исключительно во временной изолированной папке `%LOCALAPPDATA%\PandaWorker\work_tmp`, которая очищается сразу после каждого фрагмента.
- **Строгий белый список команд (`executors.py`, `panda_protocol.py`):** запускаются только фиксированные бинарники `Real-ESRGAN` / `Real-CUGAN` / `RIFE` / `FFmpeg` с проверкой контрольных сумм `SHA-256`.
- **Защита вашей видеокарты (`gpu_probe.py`):**
  - Автоматическая пауза при запуске популярных игр (`CS2`, `Dota 2`, `Valorant`, `GTA V`, `Cyberpunk 2077`, `Fortnite` и др.).
  - Автоматическая термозащита (пауза при `84°C` до остывания карты до `76°C`).
  - Автоматическая пауза при переходе ноутбука на питание от батареи.
