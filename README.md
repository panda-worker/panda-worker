# 🐼 Panda AI — GPU Helper (`PandaWorkerSetup.exe` v2.0)

Официальный клиент распределённого ускорения нейросетей **Panda 4K AI** для Windows 10/11 (64-bit).

Программа позволяет владельцам игровых видеокарт (от **8 ГБ VRAM**) помогать ускорять анонимные фрагменты апскейла в фоновом режиме и ежедневно получать **бесплатные Дневные Пакеты 4K Фото + 60 FPS Видео** в Telegram-боте [@b1gme_bot](https://t.me/b1gme_bot).

---

## 📥 Скачать программу

👉 Перейдите в раздел **[Releases (Справа на странице)](../../releases/latest)** и скачайте **`PandaWorkerSetup.exe` (~16 МБ)**.

> *(Архив `panda_engines_pack.zip` вручную качать **не нужно** — программа сама тихо докачает его в фоновом режиме после ввода 6-значного кода!)*

## ⚡ Как подключиться за 1 минуту

1. Скачайте и запустите **`PandaWorkerSetup.exe`**.
   - *Примечание о Windows SmartScreen:* так как проект бесплатный и не использует платную корпоративную подпись Microsoft EV ($400/год), при первом запуске Windows может показать синее окно *«Система Windows защитила ваш компьютер»*. Нажмите **«Подробнее»** → **«Выполнить в любом случае»**.
2. Откройте Telegram-бота **[@b1gme_bot](https://t.me/b1gme_bot)** → раздел **«⚡ Бесплатный пакет за GPU»** → нажмите **«🔑 Получить 6-значный код привязки»**.
3. Введите 6 цифр кода в окно программы.
4. **Готово!** Программа тихо в фоне докачает проверенные Vulkan-движки (`Real-ESRGAN`, `Real-CUGAN`, `RIFE`), проведёт тест видеокарты и пришлёт вам уведомление прямо в Telegram, когда начнёт зарабатывать ваш Дневной Пакет!

## 🛡 Полная прозрачность и безопасность (Почему этому коду можно доверять)

Весь исходный код клиента опубликован прямо в этом репозитории (`.py` модули и скрипт сборки `build_exe.ps1` — любой разработчик может изучить каждую строчку или собрать `.exe` самостоятельно):

- **0 открытых портов:** программа работает строго через исходящие HTTPS-запросы (не открывает входящих портов на вашем роутере или в брандмауэре Windows).
- **Никакого доступа к личным файлам:** работа ведётся исключительно во временной изолированной папке `%LOCALAPPDATA%\PandaWorker\work_tmp`, которая очищается сразу после каждого фрагмента.
- **Строгий белый список команд (`executors.py`, `panda_protocol.py`):** программа физически не принимает shell-команды из сети — запускаются только фиксированные бинарники `Real-ESRGAN` / `RIFE` / `FFmpeg` с проверкой контрольных сумм `SHA-256`.
- **Защита вашей видеокарты (`gpu_probe.py`):**
  - Автоматическая пауза при запуске популярных игр (`CS2`, `Dota 2`, `Valorant`, `GTA V`, `Cyberpunk 2077`, `Fortnite` и др.).
  - Автоматическая термозащита (пауза при `84°C` до остывания карты до `76°C`).
  - Автоматическая пауза при переходе ноутбука на питание от батареи.

## 💻 Системные требования

- **ОС:** Windows 10 / Windows 11 (64-bit)
- **Видеокарта:** Дискретная видеокарта с поддержкой Vulkan и объёмом видеопамяти **не менее 8 ГБ** (NVIDIA GeForce RTX 3060 / 4060 / 5050 / 4070 / 4080 / 4090 или AMD Radeon RX 6600 / 7600 и выше).
  - *Если видеокарта слабее 8 ГБ или встроенная — программа вежливо сообщит об этом при запуске и аккуратно удалит себя без остатка.*
- **Свободное место на диске:** от 2.5 ГБ (докачка нейросетей умеет продолжаться с того же процента даже при слабом интернете или выключении ПК).
