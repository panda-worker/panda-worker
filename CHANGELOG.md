# Изменения воркера

## 2.5.1 (2026-11-19)
Новый интерфейс в стиле «PANDA production» (обновление необязательное, `min_required = 2.5.0`):
- Окно полностью перерисовано: чёрно-белый стиль «краска и плёнка» — стекающая краска,
  панда с валиком, киноплёнка, надпись PANDA production; скруглённые карточки, плитки
  режимов нагрузки 2×2 с иконками, полоса прогресса «валиком», 6 ячеек для кода привязки.
- Своя иконка программы (exe, панель задач, заголовок окна) вместо стандартной иконки Python.
- Чёткая отрисовка на экранах с масштабом 125–200 % (DPI-aware), окно всегда помещается на экран.
- Дочерние процессы никогда не открывают консольных окон.
- На экране нет личных данных; адрес сервера спрятан под «Дополнительно».
- Все функции прежние: проверка оборудования и самоудаление, привязка по коду, автозапуск,
  режимы нагрузки, пауза, смена кода, полное удаление, сворачивание по крестику.
- Шрифт интерфейса — Nunito (SIL Open Font License 1.1, `ui_fonts/OFL.txt`).

## 2.5.0 (2026-11-19)
Безопасность и надёжность (обязательное обновление, `min_required = 2.5.0`):
- Подключение к серверу только по TLS (`https://130.61.36.196:8790`), сертификат сервера
  вшит в сборку (`panda_server_ca.pem`, pinning). Старый адрес `http://` переводится автоматически.
- Обновления и пакет ИИ-движков устанавливаются только с проверенной Ed25519-подписью
  (`release_verify.py`, ключ вшит). HMAC-фолбэк удалён, даунгрейд запрещён.
- Релизы на GitHub сопровождаются подписанным манифестом `SIGNATURES.json` + `.sig`.
- Загрузки: максимум 3 перекачки при неверном SHA, лимиты размера, защита от zip-bomb/zip-slip,
  атомарная установка движков и hot-update, корректный откат версии.
- Агент: один поток heartbeat и обновлений, отзыв ключа -> остановка и просьба перепривязать,
  без двойных отчётов об ошибках, лимит входного файла, claim без блокировок на время сети.
- Удаление программы стирает только папку Panda Worker.
- Включены исправления 2.4.1–2.4.7 (самопроверка без падения, поиск движков rglob, `_isf`).

## 2.3.0 (2026-10-31)
- Правило размера кадра: `min(потолок тарифа, max(2×исходник, 1024))`, коэффициент 2/3/4,
  модель `realesr-animevideov3-x3/x4` с честным откатом на x2.
- Кэш метаданных ffprobe (было 2–3 запуска на задачу).
- Сборка MP4: NVENC `p4` + `lookahead 8` (было `p6`/16).
- Распаковка кадров в JPEG q=3 вместо q=2.
- Фото: убран перешарп (unsharp 130% → 60%, авто-профили мягче).
